七步完成自主光谱实验

按顺序完成任务 1 到任务 7：先验证硬件和读数稳定性，再做人机对比、独立复测与仿真统计。

步骤本步目标
1. 接线与试灯按图接好 9 根线，试红、绿、蓝，观察 8 通道光谱变化。
2. 校准与质检采集暗场与白光参考，再固定配方连测 5 次，确认波动 < 5%。
3. 调色比赛同一目标下，分别用人类、Random、BO 搜索最佳 RGB 配方。
4. 独立复测固定各方法找到的最佳配方重测 20 次，比较均值与波动。
5. 多种子仿真在仿真模式下跨种子、跨预算批量对比 Random 与 BO。
6. 测量可信度在仿真模式下做“正常 → 漂移 → 恢复”三组对照。
7. 保存与归档导出 JSON / JSONL / CSV 数据，结束本轮。
真机与仿真操作一致，所有数据都会自动落盘保存。
拓展任务：UniLabOS 三色测量工作流

完成七任务后，可按发布包 integrations/unilab/README.md 在 UniLabOS 0.12.3 中运行“连接 → 自检 → 测红/绿/蓝 → 保存 → 关灯断开”工作流（仿真已验证，真机需现场联调）。

1. 接线与试灯

填好组名、核对 9 根接线，然后在下方调节红/绿/蓝，确认灯光颜色与光谱峰值波段一致。

更多设置（抽签种子 / 实验前预测）

实物接线核对（9 根公对公，断电接线）

点击图片可放大查看细节

Pico 跨面包板中沟、USB 口朝上。选两排互不连通的空孔分别作 P（3.3V）和 G（GND）。

  • 3V3 OUT→P1
  • GND→G1

仅使用 3.3V 供电，不接 VBUS / 5V。固定光路并遮光后再插 USB。

白色三芯插头接灯板，公对公线经黑色母头连到面包板。

  • P2 (3.3V)→灯 ＋
  • G2 (GND)→灯 －
  • GP28→灯 DI

灯板另一端 DO 输出留空不接。

白色六芯插头接 AS7341，按丝印核对以下 4 根线。

  • P3 (3.3V)→VCC
  • G3 (GND)→GND
  • GP26→SDA
  • GP27→SCL

INT 和 GPIO 留空，不接电源或地。

试灯与实时光谱

点击下方「纯红 / 纯绿 / 纯蓝」或拖动滑块实测，确认红光约 630 nm、绿光约 515 nm、蓝光约 480 nm。

小组讨论记录（选填）：换一种灯光颜色，哪些光谱柱子变化明显？

2. 校准与质检

固定好灯和传感器位置，先采集暗场与白光参考，再固定点连测 5 次，确认波动 < 5%。

未通过时先检查固定与遮光，再重新校准和测 5 次。重新校准会自动归档旧轮次。

小组讨论记录（选填）：为什么比赛前要先检查读数是否稳定？

3. 调色比赛

先点「随机神秘盲盒目标」，再分别完成人类调色、Random 和 BO 搜索，比较谁的谱差 L 更小。

Random / BO 共用预算，出题后锁定；人类次数可独立选择。
小组讨论记录（选填）：谁更接近目标？各自用了多少次？

4. 独立复测

固定每种方法找到的最佳配方重新测多次，检验好成绩是稳定复现还是偶然运气。

搜索过程曲线

● 人类 ● Random ● BO 实线 = 单次 L(x) · 虚线 = 迄今最佳 best-so-far

固定最佳配方重新测量

复测结果不回写搜索历史，不改变最佳配方。

小组讨论记录（选填）：复测之后，刚才的好成绩还可靠吗？

5. 多种子批量仿真

固定同一目标，换多组抽签编号和预算反复比较 Random 与 BO，看统计表现而非单次输赢。

当前为真机模式，批量研究仅在仿真启动器中可用。

平局阈值 |ΔL| ≤ 0.001；各预算取同一最大预算轨迹前缀。仿真数据不可替代真机结论。

小组讨论记录（选填）：增加次数后，BO 是否每一轮都赢？

6. 测量可信度对照（仿真）

保持 RGB [0.5, 0.5, 0.5] 与校准不变，依次测三组，观察测量条件漂移对读数的影响。

助教排障参考：超时与饱和

串口超时：未收到读数不等于 0；真机应查数据线、串口占用与固件响应。

传感器饱和：任一通道 ≥ 60000 即判饱和，需调整遮光、距离或曝光后重新校准。

小组讨论记录（选填）：RGB 没变，为什么第二组读数变了？

7. 保存与归档

记录本组结论并下载原始数据，结束本轮后即可解锁参数开启下一轮。
