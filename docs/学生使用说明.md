# Pocket SDL Classroom 学生与教师使用说明

## 1. 启动

解压整个目录，不要只拷贝启动文件。电脑需 Python 3.10+（建议统一 3.12）。首次启动需要联网安装 numpy 和 pyserial，课程前完成安装彩排。

| 用途 | macOS | Windows | 教师页面 | 局域网观众端口（可选） |
|---|---|---|---|---|
| 真实设备 | Start Pocket SDL.command | Start Pocket SDL.bat | http://127.0.0.1:8770/ | 默认关闭（命令行 `--audience-port 8771` 开启） |
| 无设备仿真 | Start Simulation.command | Start Simulation.bat | http://127.0.0.1:8772/ | 默认关闭（命令行 `--audience-port 8773` 开启） |

真机失败不会切换到仿真。USB 须支持数据传输。固件由助教提前配置，使用普通插入，不按 BOOTSEL；出现 RPI-RP2 表示尚在固件烧录模式。此工具不会自行刷写固件。如果 macOS 禁止直接双击 `.command`，可在终端进入本目录运行 `bash "Start Simulation.command"` 或 `bash "Start Pocket SDL.command"`。

旧真机台若仍运行，先在旧启动终端按 Ctrl+C 关灯、释放串口。不要让两个服务同时操作同一设备。新版探测到 8766 的旧真机启动器会停止并提示，不强制关闭旧服务。重新双击若提示端口占用，直接打开上表中的既有页面，或先退出旧启动终端。

## 2. 一轮完整操作

1. **① 接线与预测**：按最新实物图接线，固定模块和遮光。填小组、算法预算（默认12）、预测，点“保存设置”。
2. **③ 实验操作 → 实时分光仪**：分别探索 R/G/B 与八通道关系。仿真不会让实物灯亮；真机必须显示 PHYSICAL。
3. **② 校准与质检**：先采暗场/参考，再固定点测5次，检查相对波动 <5%。失败则修复位置与遮光；不要直接开始比赛。
4. **③ 实验操作 → 人机调色擂台**：随机隐藏目标，或输入教师指定目标。人类手动尝试，然后分别运行 Random 与 BO。人类预算在擂台独立选择，Random与BO预算一致；AI前4点显示在课程页，种子/预算锁定。
5. **④ 独立复测**：区分每次损失实线和最佳损失虚线。固定各方法已找到的最佳RGB，选择3次快速检查或20次课堂复测，检查每种方法均值、样本标准差及实际次数。复测不再优化，不改变搜索结果。
6. **⑤ 多种子批量对比**：真机与仿真均可执行，先完成校准、质检和固定目标。各预算复用最大预算轨迹前缀；默认共240次采样，页面显示总次数与进度，可停止并保留部分数据。真机逐配方实测，仿真结果明确标注来源。
7. **⑥ 色片测量可信度对照**：同一RGB与校准下，依次不放色片、加入色片、移除色片，各测5次。真机须手动放稳或移除后点击，颜色仅是记录标签；仿真使用示意透过率。比较平均光谱和重复波动，固定色片不一定增大波动。
8. **⑦ 保存与分享（归档）**：填结论保存；下载 JSON、JSONL 和 CSV。点“结束并归档本轮”，解除轮次参数锁后设置下一轮。

## 3. 数据与公平性

- 相似度=100×exp(−3L)，是展示分值，不是准确率。人类接近100%不意味着系统坏了。
- 人类看谱图反馈，算法按各自规则选点；同次数不等于信息完全对等。人类提前停止时，要报告实际次数，不能写成同次数完成。
- 相同seed且同预算，Random/BO共享前4个候选，分别采集真实读数。实机读数不应被强制复制一致。
- 移动装置后旧目标/校准不再适用，应重新校准、检查并新建目标；软件无法自动判断你是否移动了传感器。
- 重校准/重连会清空当前比较，但旧数据留在JSONL。数据归档跨重启保留，不自动恢复旧校准和未完成控制任务。
- JSON最新快照包含批量对比、色片实验、独立复测明细；JSONL保留追加历史；CSV包含真机及仿真逐次采样、模式、色片阶段、批次编号、seed、算法与迭代序号。
- 导出含教师隐藏目标，挑战结束后再分享。

## 4. 教师准备

先在每组电脑完成依赖安装和模拟流程。真机硬件固件沿用已验证的GP26/GP27/GP28版本。课堂开始前，用新版连接一组实机，完成点灯、校准、5次质检、搜索、20次复测、关灯验收；再扩展到全班。

本版软件自动测试和完整仿真验收已完成；未代替真实设备与全班网络现场验收。课程安排见 [180 分钟课程与任务单](180分钟课程与任务单.md)。
