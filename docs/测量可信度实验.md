# 色片测量可信度对照

任务六支持 PHYSICAL 与 SIMULATED，先完成任务二暗场与白光参考校准。

1. 不放色片，固定 RGB [0.5, 0.5, 0.5]，测5次基线。
2. 选择色片颜色。真机手动放稳色片后测5次；仿真采用对应示意透过率。
3. 真机手动移除色片后测5次，检查光谱恢复；仿真自动移除模型。

真机读数直接来自 AS7341，颜色标签不改变数值。三组保持位置、曝光、遮光和校准一致；重新校准或重连后需从基线重做。

图表展示三组八通道平均原始光谱及每组五次总读数，重复波动小于5%表示稳定，不代表色片没有改变光谱。任务六不覆盖任务二的质检结果；若继续调色比赛，移除色片后重新校准、质检。

完成、中断或异常后自动关灯；超时和饱和不会补零。JSON/JSONL记录模式、校准、分组与原始读数，CSV记录mode、color_filter、reliability_stage。API阶段沿用baseline/drift/recovery。

自动测试覆盖真机接口替身、原始读数不被改写、中断、异常、校准失效与导出。软件测试不能替代实物色片验收。
