# 测量可信吗？约10分钟对照实验

入口：仿真研究 → 测量可信吗？仅支持SIMULATED。先完成暗场与参考校准。

1. 先预测三组中哪组波动最大，再点正常测量5次。
2. 点加入漂移，再测5次。RGB和校准不变，仅对读数交替缩放，模拟测量条件变化。它不是实际位置变化的精确模型。
3. 点恢复正常，复测5次。并排比较三组的新读数及八通道相对波动。

柱图采用同一尺度，展示每次八通道总读数；质检采用原有八通道相对波动公式，要求小于5%。未完成、失败或中断不放行。漂移仅作用于第二组采样，结束自动关闭；质检失败仍需复测通过。

课堂问题：RGB没有变，第二组为何变化？只看最低误差会误判什么？真实装置移动后，应重新校准、检查稳定性并新建目标，不能把仿真恢复通过理解成真实旧目标自动有效。

超时/饱和移至折叠的助教排障参考。原故障API为兼容保留，不再作为学生主界面操作。

验收：66项自动测试通过；HTTP三步验证通过。样例相对波动：正常0.315%、漂移36.939%、恢复0.317%，均为仿真数据，非实机指标。
