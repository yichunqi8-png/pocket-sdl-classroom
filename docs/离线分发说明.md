# Pocket SDL 离线课堂包

2026-11-27。面向无法访问 GitHub 的 Windows 和 Mac 课堂电脑。

## 使用方式

完整解压对应平台 ZIP，双击 `Start Simulation` 或 `Start Real Device`。包内包含 Python、NumPy、pyserial 和全部界面/接线图，无需安装 Git、Python、pip，也不在首次运行时下载依赖。云端仅用于分发，设备与数据在本机运行。

- Windows-x64：Windows 10/11 x64。
- Mac-Apple：Apple 芯片。
- Mac-Intel：Intel 芯片。

真机仍需助教预先配置 Pico 固件。UniLabOS 环境不包含在此包中。

## 打包与验证

工作流 `.github/workflows/offline.yml` 在三个平台分别构建，使用 Python 3.12、NumPy 2.2.6、pyserial 3.5、PyInstaller 6.16.0。

`packaging/build_offline.py` 生成独立运行目录、双击入口和 ZIP；Mac ZIP 保留框架符号链接。`packaging/smoke_offline.py` 在中文和空格路径中运行冻结程序，清空 PATH/PYTHONPATH，检查页面、接线图、三色测量和记录生成。

三平台构建与测试通过：https://github.com/yichunqi8-png/pocket-sdl-classroom/actions/runs/45966026369 。下载后的 Intel Mac ZIP 另在本机解压，检查页面、串口枚举及仿真测量通过。没有将这些检查表述为真机或任意旧系统验收。

## 数据位置

- Windows：`%LOCALAPPDATA%\Pocket SDL\classroom-data`
- Mac：`~/Library/Application Support/Pocket SDL/classroom-data`

程序升级不删除此目录。可以在任务七导出实验记录。
