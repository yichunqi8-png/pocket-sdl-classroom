# Pocket SDL Classroom 课程版设计

基于 ZiWei09/pocket-sdl 90012ec 的本地开发版独立复制，保留上游许可、固件和硬件保护。原运行目录不修改。

用户已授权补齐课程环节：以现有控制台为实验操作页，增加课程工作台：小组记录、稳定性准入、同预算与同初始点对照、固定最佳点独立复测、持久归档/导出、纯仿真多种子预算研究和故障演练。默认真机启动，仿真必须明确选择。手机只允许出题和公开状态，不授予教师控制权。

校准变化、设备重连必须废弃当前准入，旧轮次归档。复测不进入搜索历史，不更新搜索最佳。仿真研究与实机账本分别标注。批量预算对比采用同一最大预算轨迹前缀，不把独立抽样误称共同初始点。

接线依据 workshop试跑 2026-11-23 可见记录：3V3 OUT 分配给灯+和传感器VCC；GND共地；GP28灯DI；GP26 SDA、GP27 SCL；DO、INT、GPIO留空；9根公对公。P/G是示意标签，不是印刷孔号。

验证：回归原有测试；新增准入/校准失效、复测隔离、归档跨重启、预算与初始化、故障、HTTP权限边界测试；仿真端到端。真机不自动占用原服务，交付时明确待实机验收。
