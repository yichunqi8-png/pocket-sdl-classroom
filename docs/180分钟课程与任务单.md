# 180 分钟课程与小组任务单

一组建议 2–4 人，轮换操作者、记录者、质检员、汇报者。不能把 3 小时都安排成等待算法运行；每段须有可检查的记录。快组扩展预算与噪声讨论，慢组先完成核心闭环。

| 时间 | 页面 / 操作 | 学生必须交付 | 教师检查 |
|---|---|---|---|
| 0–20 分 | 课程路线、① 接线与预测 | 一条预测与理由；输入、输出、目标、loss 的对应关系 | 不把相似度当准确率，不承诺 BO 必胜 |
| 20–45 分 | 最新接线图、③ 实时分光仪 | 九根线逐项核对；R/G/B 各观察一组通道响应 | USB断开后接线；INT/GPIO/DO留空；固定位姿 |
| 45–65 分 | ② 校准与质检 | A、SNR、5次固定点相对波动、通过/失败原因 | 不通过不得进入搜索；解释校准与稳定性区别 |
| 65–90 分 | ③ 人机擂台 | Random/BO各12次、人类独立预算；记录seed、目标轮次、AI前4点、各自实际次数 | 人类可提前完成但注明实际次数；实验中不移动 |
| 90–100 分 | 休息 | 保持光路位置 | 关灯即可；不要改接线 |
| 100–125 分 | ④ 独立复测 | 每方法20个新读数；搜索最低值、复测均值、样本标准差 | 复测不算搜索、不挑最好的一次冒充平均表现 |
| 125–150 分 | ⑤ 多种子对比 | 5种子×8/16/24预算；均值、最差、胜/平/负；一个反例或限制 | 真机逐候选实测；先查看总采样次数与进度，明确数据来源 |
| 150–165 分 | 任务六 · 色片对照 | 不放→加入→移除色片三组光谱及重复波动对照（可选：CLI 开启局域网观众出题） | 不带电拔线制造故障；说明真机位移后须重新校准并建新目标 |
| 165–180 分 | ⑦ 归档、小组汇报 | 结论、证据文件、1条限制、下轮改进 | 文件注明模式；JSONL包含所有轮次，防止只保留最好一轮 |

## 对原课件流程的对应更新

- 开发板与接线页：使用此包的最新实物图；板名为 Type-C RP2040 Pico 兼容板，排针已焊接，课程固件助教预装。
- 质检页：现在可直接点击5次稳定性检查并看到准入结果；不能只展示A和SNR便跳过重复性。
- 人机对照页：默认Random/BO各12次、人类独立预算；明确人类看到谱图，AI共用前4候选，读数各自重新测。不要把旧截图10次对24次称为同预算。
- 收敛曲线页：区分单次L与best-so-far，新增页提供两条线。
- 固定配方20次复测页：新增独立复测按钮可直接执行；图例对应搜索最佳/新测均值/样本标准差，不再靠人类测量按钮凑次数。
- 多种子/多预算页支持真机与仿真，采用同最大预算轨迹的前缀；记录并明确展示实际数据来源。
- 故障页：超时、饱和、漂移只在仿真注入。不要安排学生带电拔线制造故障。
- 手机/云实验页：七任务默认界面聚焦单机课堂（双击启动默认 `--audience-port 0`）；如需同局域网观众出题，可通过 CLI 指定 `--audience-port 8771/8773` 或使用原版 `workshop/server.py`，且需同 Wi-Fi 和可达端口，不是公网云实验。
- 结课页：增加数据导出、独立复测证据和小组结论，而非完成一次调色就结束。

本文件提供课程对应关系，未直接改写原飞书讲稿/PPT，也不把旧演示数值替换成未经实机验证的新数据。
